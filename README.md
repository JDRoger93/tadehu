# Autosugestión FunTaDeHu ✨

> *"Para Ser Eficaces y Felices"*

Aplicación web progresiva (PWA) de autosugestión diseñada para ejecutarse en el teléfono u ordenador con notificaciones periódicas aleatorias y funcionamiento **100% Offline**.

---

## 🌟 Características

- **🔔 Notificaciones Aleatorias:** Envío periódico de frases de autosugestión durante el día para reprogramar la mente subconsciente.
- **⏸️ Modo Descanso:** Botón dedicado para pausar y desactivar las notificaciones cuando desees desconectarte.
- **▶️ Reactivar:** Botón para reanudar el ciclo de recordatorios al instante.
- **➕ Gestión de Frases:** Agrega o elimina frases de autosugestión personalizadas del libro.
- **📶 100% Offline:** Gracias al Service Worker integrado, la app funciona completamente sin conexión a internet ni consumo de datos.
- **📲 Instalable (PWA):** Se instala directamente en la pantalla de inicio de Android e iOS con el icono oficial de FunTaDeHu.
- **🔕 Sin Publicidad ni Marcas:** Interfaz limpia optimizada para lectura cómoda.

---

## 🚀 Despliegue en Netlify

El repositorio está enlazado directamente a Netlify. Cada `git push` a la rama `main` compila y publica automáticamente la versión más reciente en producción.
